Всем привет, дорогие поклонники!

Рады представить вам нашу игру "Виселица". Программа написана на C++ с использованием SFML и собрана при помощи CMake.

Игроку необходимо угадать скрытое слово из 7 букв, связанное с тематикой еды, выбирая буквы с помощью наведения мышки на букву на интерактивной клавиатуре.

Игра заканчивается победой при отгадывании слова или поражением после достижения максимального количества ошибок. При желании игрок может покинуть приложение или начать заново.

##Возможности:
  1) Графический интерфейс на SFML
  2) Случайный выбор слова из составленного словаря
  3) Обновление изображения виселицы после ошибок
  4) Отключение кнопок после нажатия
  5) Экран "You win!" "Game over!"
  6) Отображение загаданного слова после завершении игры
  7) Кнопка Try again для любителей страдать заново

##Запуск программы происходит следующим образом:

на Macos: 

cmake 

make

./Example3_Buttons

на Windows:

cmake -S . -B build -G "MinGW Makefiles" 

cd build

cmake --build .

.\Example3_Buttons.exe
